# Sua carreira está bem arquitetada?

Formulário de autoavaliação da palestra **"Sua carreira está bem arquitetada? Descubra em 6 pilares"**, de Josilene Silva, no AWS Community Day Brasil, Edição Norte (Belém, 31/10/2026).

São 18 afirmações, 3 por pilar do AWS Well-Architected Framework. Cada uma está ligada a um princípio de design do pilar. A pessoa responde com as cores do semáforo, uma pergunta por vez, e no final recebe:

- um relatório de riscos por pilar, com a pontuação de 0 a 36;
- o pilar para começar e uma ação para ele;
- um plano de melhoria para os próximos 30 dias.

## Como funciona

- É uma página única: `index.html`, sem build e sem dependências além da fonte Montserrat do Google Fonts.
- As respostas ficam só no navegador da pessoa (`localStorage`). Nada é enviado para servidor nenhum.
- Quem fecha no meio pode continuar de onde parou.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `revisao-carreira`.
2. Envie esta pasta para ele.
3. No repositório, vá em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`, e salve.
4. O endereço fica parecido com `https://SEU-USUARIO.github.io/revisao-carreira/`. Use esse link para gerar o QR code do slide 37.
